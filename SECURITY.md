# Security Policy

Datadog takes security issues seriously.

If you believe you have found a security vulnerability in this repository, please do not open a public GitHub issue. Report it through Datadog's vulnerability disclosure program:

https://www.datadoghq.com/security/

Include enough detail to reproduce and assess the issue, including affected versions, configuration, platform, and any proof of concept you can safely share.
